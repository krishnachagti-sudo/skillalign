# Team

Each of us adds one small piece to SkillAlign from our own GitHub account. About 15-20 minutes, all in the browser, nothing to install.

**How:** sign in to GitHub → open your link → type in the editor → **Commit changes** → **Create pull request**. (The first time, GitHub asks to "fork" the repo: say yes.) That's it. Krishna merges it, and it shows on the live site.

Each link opens your file ready to fill in. The lines starting with `#` explain what to write.
